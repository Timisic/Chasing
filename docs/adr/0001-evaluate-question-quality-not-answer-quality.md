# 评测模型提问质量，而不是回答质量

绝大多数 AI 学习产品和评测项目都在评模型回答得好不好。我们选择评测模型**问得好不好**——苏格拉底式提问的质量。这是因为：(1) 真正有效的学习发生在"被好问题逼着自己想"的时候，提问质量直接决定学习效果；(2) "好问题"的评测维度几乎没有公开的标准答案，需要自己设计，而"定义好"正是产品经理最核心的能力展示；(3) 评测回答质量已经有大量公开工作（MMLU、MT-Bench 等），差异化空间小。

## Considered Options

- **评测回答质量**：成熟领域，有大量现成框架和 benchmark，容易做但没有差异化
- **评测提问质量**：新领域，没有标准答案，需要自己从 bad case 中归纳维度——风险更高但展示的能力更稀缺
